🍅 Pomodoro Camera — Embed Demo

Three ways to embed. Build first: npm run build then open dist/embed.html or use dist/pomodoro-embed.js.

1. Web Component (Shadow DOM, isolated)

Drop-in custom element. Attributes are reactive.

<script type="module" src="/dist/pomodoro-embed.js"></script>
<pomodoro-camera theme="dark" pomodoro="25" break="5"></pomodoro-camera>
<pomodoro-camera theme="light" compact></pomodoro-camera>

2. JavaScript API

<div id="my-widget"></div>
<script type="module">
  import { mountPomodoro } from "/dist/pomodoro-embed.js";
  // or: window.PomodoroCamera.mount(...)
  const el = mountPomodoro("#my-widget", { theme: "dark", compact: true });
  el.addEventListener("pomodoro-ready", ({ detail: { app } }) => {
    console.log(app.timer, app.vision);
  });
  el.start(); el.pause(); el.reset(); el.setTheme("light");
</script>

3. iframe (zero JS, CMS-friendly)

<iframe
  src="/embed.html?theme=dark&pomodoro=25&break=5"
  allow="camera; microphone"
  width="520" height="600"
  style="border:0; border-radius:14px"
  loading="lazy"
></iframe>

Attributes & Options

theme="dark|light|xp"   pomodoro="25"   break="5"   camera="false"   compact   width="400px" height="500px"

All attributes are observed — changing them updates the widget live. Events: pomodoro-ready with detail.app.
